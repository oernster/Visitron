After you install it

  • Downloads work straight away. Add a website and the downloads of its public GitHub releases appear after the first check.
  • Page loads need GoatCounter. Open the Guide from the Help menu: it shows the tag to put on your pages, then where to enter your GoatCounter account name and key in Settings.
  • Optional: a GitHub token. Worth adding if you watch many websites, so GitHub's rate limit does not slow a check.
