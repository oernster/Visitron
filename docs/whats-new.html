What's new

Recent releases have focused on seeing your figures more widely and reading them correctly. Visitron reached macOS and Linux, then gained a map of every website's visitors by country. The newest releases match page loads to a website kept in a folder even when the address lacks its final slash; the Since last check column now counts the latest release's downloads since your previous press of Refresh.

v1.5.0

Since last check counts the latest release

  • The column added up every file of every release, so one crawler fetching each old file once could show as +169 on a day the newest release had four downloads. GitHub counts such a fetch like any other; its size alone cannot tell it from genuine interest
  • It now counts only the downloads of each repository's latest release between your last two presses of Refresh. A release published between the two counts all its downloads so far, so the column does not read 0 on release day
  • Every other figure still counts every release: downloads over the period, downloads to date, the daily chart and the tables in Statistics
v1.4.2

Since last check counts from your previous Refresh

  • The column measured from the last day Visitron had run rather than from the previous check, so it crept up with every automatic check; after a restart it could hold days of downloads under a label that suggested minutes
  • It now shows the downloads between your last two presses of Refresh, from the window or the tray. Each reading is kept in Visitron's data file, so a restart or an automatic check leaves the figure as it was
  • With no earlier press to compare against, the column shows 0 until you have pressed Refresh twice on this version
v1.4.1

Page loads found when an address lacks its final slash

  • A visit to a website kept in a folder, such as example.com/app, that arrived without the final slash was counted against the whole host or against nothing. Such a website could show no page loads while GoatCounter's own dashboard listed them
  • Visitron now reads the address as the folder it names, so example.com/app counts for example.com/app/ while example.com/apple still does not. The same rule decides each website's visitors by country
  • Page loads already in your history are reassigned the next time the figures are shown; nothing is fetched again
v1.4.0

World visitors: every website's visitors on one map

  • A new World visitors button shows where your visitors come from across every website at once: a map of the world shaded by country over the period you chose, with a table of every country beside it, largest first. Point at a country to read its figure
  • The shades rise on a logarithmic scale, so a country that sent a handful of visitors still stands out next to one that sent hundreds; the key under the map gives the counts each shade covers
  • GoatCounter counts these visitors across all your websites in one go, so the totals need not add up to each website's own Statistics
  • The map's shapes come inside Visitron: drawing it contacts no map service
  • The Guide describes the new button; About credits the open map data and libraries it is drawn with
v1.3.0

Visitron on macOS and Linux

  • Visitron now runs on macOS on Apple Silicon as a signed, notarized disk image and on Linux as a Flatpak, alongside the Windows setup program; the download page offers all three
  • On macOS and Linux there is no tray: closing the window quits Visitron and the daily check runs while it is open. Starting at sign-in stays a Windows setting
  • Your GoatCounter key and GitHub token are kept in each system's own store: Credential Manager on Windows, the Keychain on macOS and the keyring on Linux. The history lives in the folder each system keeps for a program's own data, where no cache clean-up can remove it
  • The update check offers the file for the platform you are on
  • The Flatpak has no access to your files; it needs only the network, the keyring and its own folders
v1.2.1

Countries beside the downloads

  • The Statistics dialog shows a website's visitors by country beside its downloads rather than beneath them, so a long list of releases no longer leaves the countries a row or two of room. Each list has the dialog's full height and scrolls under its own heading
  • The Guide describes the new arrangement
v1.2.0

The list and the detail scroll apart; a tidier Statistics dialog

  • A vertical rule divides the website list from the selected website's detail; each side scrolls on its own. The Period chooser and the table's headings stay in view while the charts stay where they are
  • The window opens a little taller, so both charts and their notes fit without a scrollbar of their own
  • The Statistics dialog is only as wide as its tables. Its headings and captions stay in place while the rows scroll inside each table
  • Releases are named by their version alone, such as v5.5.6. Where a website's releases come from more than one repository, each version keeps its repository's name in front of it
  • Fixed: the shorter platform and repository tables no longer stretch to the height of a long list of releases
v1.1.0

Statistics for each website, with visitors by country

  • Every row in the website list has a Statistics button; Enter on the list opens the same. It shows downloads to date by platform, repository and release, then visitors by country from your GoatCounter account over the period you chose
  • Downloads carry no country, since GitHub does not record one. Where GoatCounter is not set up or cannot be reached, the dialog says so and still shows the downloads
  • The tables by platform, repository and release moved into this dialog, leaving the main window to the list and the daily charts
  • Releases are listed newest first, reading version numbers as numbers, so 1.10.1 sits above 1.9. Anything with no counted downloads is left out rather than shown as 0
  • Fixed: the tray icon vanished for good when Windows restarted its taskbar. It now returns as soon as the taskbar does
v1.0.0

The first release: page loads and downloads in one window

  • Page loads from your GoatCounter account beside downloads from each website's GitHub releases, by repository, release and platform. Choose 7, 30, 90 or 365 days, with a chart of every day
  • Add a website by its address and Visitron reads the site to propose the GitHub repositories it offers; you tick which count. A website is an address prefix, so example.com/app gets its own figures apart from example.com
  • GitHub keeps only running totals, so the daily history starts at Visitron's first check; the window says so when a period reaches further back
  • If you download each macOS disk image yourself, Settings can take that many off every .dmg count
  • Visitron sits in the tray and checks every 24 hours by default. Refresh checks at once; a failed check leaves a warning on Refresh until a later one succeeds
  • The GoatCounter key and the optional GitHub token are kept in Windows Credential Manager
  • A Help menu holds the Guide, About, the licence and Check for updates. A daily check for a newer Visitron can be turned off in Settings
  • Every control can be reached from the keyboard. The window opens dark, with a button to move it to light
  • A setup program installs Visitron for your own Windows account with no administrator rights
