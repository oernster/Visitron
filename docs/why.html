Why

Two counters that never meet.

GoatCounter knows how many people read your pages. GitHub knows how many times each release file was downloaded. To see both you open two dashboards; to see a trend in downloads you open none, because GitHub keeps only a running total.

Visitron asks both on a schedule, keeps a snapshot each day and turns those totals into downloads per day. It knows which repositories belong to which website, so every figure lands on the right row.

One thing it cannot do: fill in the past. GitHub publishes a running total only, so the download history starts at Visitron's first check. Until the history covers the period you chose, the column names the day counting began, so a 0 is never mistaken for a quiet month.

What it needs from you

  • Windows. Visitron is a Windows application; there is no macOS or Linux version.
  • For page loads: your own GoatCounter account. Each page you want counted carries GoatCounter's two-line tag, which the Guide gives you to copy. In Settings you enter your account name and an API key from GoatCounter. Without them Visitron still shows downloads and says where the page loads would be.
  • For downloads: public GitHub releases. No account is needed. An optional GitHub token lets Visitron ask GitHub more often before GitHub's rate limit stops it. Private repositories are not read.

Exactly what it talks to

Visitron contacts these places and nothing else. It sends no telemetry.

  • GoatCounter, at your own account, with your key, to read page loads.
  • GitHub's API, without a login or with your token, to read the download counts of the repositories you ticked.
  • Your own websites, when you add or edit one, to find the repositories they name.
  • Visitron's own GitHub releases, shortly after it opens and once a day, to see whether a newer Visitron exists. Turn it off in Settings; Check for updates in the Help menu still asks when you choose it.
  • The donation page, opened in your browser, only when you press Donate.

Your figures stay on your computer, in one file in your own profile. Your keys stay in Windows Credential Manager and each one is sent only to its own service.

What it will not do

Said plainly, so nothing comes as a surprise.

  • It does not run on macOS or Linux.
  • It does not count clicks or any event other than a page load.
  • It does not show referrers or browsers, though GoatCounter holds them. It shows visitors by country; it cannot show downloads by country, since GitHub does not record where a download came from.
  • It does not change anything on GoatCounter or GitHub; it only reads.
  • It does not read releases from anywhere but GitHub, nor statistics from anywhere but one GoatCounter account.
  • It does not send notifications when figures change.
  • It does not export its figures.
